MS2 — Full Bone Set (MorphoSource Aleph Embeds)

Five MorphoSource Universal Viewer / Aleph embeds for the same mystery specimen, testing whether real 3D bone meshes can render and be measured directly in a page we control — no local ImageJ, no manual conversion. This page's network cannot reach morphosource.org from inside the build environment, so it has to be opened and checked by a human on a real connection.

What to check when you open this:
  • Does each panel actually load the 3D model, or show an error / blank space?
  • Can you rotate/pan/zoom each mesh with the mouse?
  • Does Aleph's built-in measurement tool appear (usually a ruler/annotation icon in the viewer's toolbar)? Try placing a linear measurement on one bone and see what units it reports.
  • Roughly how long does each model take to load — instant, a few seconds, unacceptably slow?
  • Note anything that looks licensing-related in the viewer itself (a copyright badge, an info panel) — screenshot it if so.
Reminder: nothing here is licensing-cleared yet — this is purely a technical viability test.
