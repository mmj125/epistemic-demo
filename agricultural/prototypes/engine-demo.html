Cycles Engine, running live in this browser

This is a validated-engine demo, not the classroom tool. It proves the from-scratch agroecosystem engine (see cycles_engine_validate.py) runs correctly in a real browser via Pyodide, no server, no backend, matching this platform's architecture. It does not yet include nitrogen rate as a student control (that was scoped but never built onto the validated engine, kept honest here rather than faked) or arbitrary field/location selection (deferred, see CLAUDE.md). Weather data is real NLDAS-2 reanalysis for Rock Springs, PA, 1980-2016, a public federal dataset independent of Cycles' own licensing.
