Cycles Engine, running live in this browser

This is a validated-engine demo, not the classroom tool. It proves the from-scratch agroecosystem engine (see cycles_engine_validate.py) runs correctly in a real browser via Pyodide, no server, no backend, matching this platform's architecture. The nitrogen slider is a simplified mineral-N balance, not Cycles' own six-pool soil carbon/nitrogen system (out of scope for v1, see CLAUDE.md) -- it assumes all crop nitrogen comes from the fertilizer you set here, with no background soil-supplied nitrogen, so the "no effect" point sits higher than a real fertilizer recommendation would (which also draws on soil mineralization this simplified model doesn't include). Soybean fixes its own nitrogen (a legume, per the real crop file) and is correctly unaffected by the slider. Arbitrary field/location selection is still deferred (see CLAUDE.md). Weather data is real NLDAS-2 reanalysis for Rock Springs, PA, 1980-2016, a public federal dataset independent of Cycles' own licensing.
